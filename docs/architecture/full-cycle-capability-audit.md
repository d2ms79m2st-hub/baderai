# تدقيق دورة Bader AI الكاملة

التاريخ: 2026-10-25

## ما هو موجود فعليًا

- كتالوج Supabase في الإنتاج: المنتجات والتصنيفات والأسعار والصور فقط، مع RLS عامة وإدارة عبر `private.is_admin()`.
- Supabase Auth و`profiles` و`chat_messages` و`human_requests`.
- مساعد متصل بـn8n عبر webhooks، مع fallback عربي آمن.
- لوحة `DashboardLayout` موجودة كـscaffold فقط، وبداخلها عناصر placeholder (`Page 1` و`Page 2`) وليست لوحة تجارة عاملة.
- لا توجد جداول أو مسارات إنتاجية للسلة أو الطلبات أو عناصر الطلب أو الدفع أو الشحن أو العروض أو المخزون أو المبيعات والتقارير.

## ما نُفذ في هذه الدورة

- فُحص أحدث commit والحالة الفعلية للمستودع وقاعدة الإنتاج.
- قورنت المنتجات العامة فعليًا عبر Supabase REST بالمصدر المحلي: 73 محليًا، 67 مرئيًا للعامة، و0 فروقات في الأسعار والروابط والصور والعملات وحالة `out_of_stock` ضمن المنتجات المرئية.
- فُعّل Supabase كمصدر افتراضي للمتجر الأساسي بعد اجتياز المقارنة.
- بقي rollback المحلي متاحًا عبر `VITE_CATALOG_SOURCE=local`.
- قُيد مساعد بدر على تمرير وترشيح المنتجات المتاحة فقط؛ لا تظهر المنتجات النافدة في توصيات البحث أو سياق n8n.
- فُحصت صلاحيات anon: لا يملك INSERT أو UPDATE أو DELETE على جداول الكتالوج.
- فُحصت `private.is_admin()`: `SECURITY DEFINER`، `STABLE`، و`search_path=public`، وتتحقق من `auth.uid()` مقابل `profiles.role='admin'`.

## ما بقي معلقًا

### الإدارة

لا توجد لوحة تجارة مكتملة يمكن توسيعها بأمان. إنشاء لوحة حقيقية يتطلب أولًا schema متفقًا عليه للمنتجات القابلة للتحرير والعروض والمخزون والتدقيق، ثم إجراءات خادمية/حماية RLS واختبارات مستخدم admin حقيقي. لم تُنشأ واجهة شكلية تدّعي أنها متصلة.

### الطلبات والمبيعات والدفع والشحن

لا توجد جداول أو provider credentials في المشروع. لا يمكن اختبار دفع أو إشعارات webhook أو منع تكرار الدفع دون حساب تاجر ومفاتيح/أسرار provider وإقرار قواعد الإلغاء والشحن والضرائب. لم تُنشأ تكاملات وهمية ولم تُدّعَ جاهزية checkout.

### المخزون

كتالوج Supabase الحالي snapshot، وتعليقه الصريح يقول إنه ليس مخزونًا مباشرًا. لا توجد كميات أو معاملات حجز/خصم ذرية؛ لذلك لم تُخترع كمية ولم يُعرض snapshot كمخزون حي.

### الأتمتة والتقارير

n8n موجود للمساعد فقط. لا توجد workflow موثقة لتنبيهات المخزون أو تقارير المبيعات، ولا يمكن إنشاء تقارير مبيعات حقيقية قبل وجود orders/payments فعلية. لم تُرسل رسائل للعملاء.

## الاختبارات الأمنية

تم اختبار صلاحيات anon والقراءة العامة فعليًا. لم يُنشأ حساب admin تجريبي ولم تُجرَ كتابة حقيقية بحساب admin؛ لذلك لا يوجد ادعاء باختبار مسار تحرير admin في الإنتاج. سيحتاج ذلك إلى حساب مالك منفصل أو بيئة اختبار مصرح بها قبل بناء لوحة الكتابة.
