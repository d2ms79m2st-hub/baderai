# قاعدة المعرفة الرسمية

يحتوي `bader-official-catalog.json` على snapshot مؤرخ للكتالوج العام لمتجر بدر أباالخيل.

- المصدر: واجهة Salla العامة لمتجر بدر (`store_id=565229011`).
- التصنيفات المجمعة: عروض اليوم الوطني، البوكسات، خشب العود، دهن العود والمسك، البخور، العطور، الزعفران واللبان، المرشات، المباخر، والإكسسوارات.
- طريقة الجمع: API عام مع cursor pagination، وليس تخمينًا من أسماء المنتجات.
- عدد السجلات الفريدة في snapshot الحالية: 73.
- كل سجل يحتوي الاسم والرابط والصورة والسعر والسعر السابق عند توفره والوصف والتوفر والوزن والتصنيفات.

## التحديث

من جذر المشروع شغّل:

```bash
python3 scripts/sync-bader-catalog.py
```

ثم راجع `collectedAt` و`productCount` وغيّر snapshot في المستودع قبل نشرها. لا تُعرض الأسعار أو حالة التوفر على أنها لحظية؛ يجب اعتبارها بيانات snapshot، والرجوع إلى رابط المنتج الرسمي عند اتخاذ قرار الشراء.

الموقع لا يملك سلة أو دفعًا أو إتمام طلب. كل بطاقة تفتح رابط المنتج الأصلي في `baderabalkhail.com`.
