# مساعد بدر — بدر أبا الخيل للعود والعطور

منصة عربية RTL بواجهة React منشورة على GitHub Pages، تتضمن صفحة محادثة كاملة الشاشة لمساعد بدر. الواجهة هي تجربة الشات، بينما يستخدم الخادم التنفيذي n8n خلفها لإنشاء مهمة ذكاء اصطناعي وإرجاع الرد؛ لا يعتمد المستخدم على لوحة n8n ولا يراها.

## ما يعمل الآن

- الموقع المنشور: `https://d2ms79m2st-hub.github.io/baderai/#/assistant`
- صفحة `/assistant` مستقلة ومتجاوبة للجوال والكمبيوتر.
- صفحة `/store` للمنتجات الموثقة وروابط الشراء الرسمية.
- صفحة `/knowledge` لشرح المصادر وحدود عدم التخمين.
- عميل React يرسل السؤال إلى `assistant-start` ثم يستعلم عن `assistant-status` حتى اكتمال الرد.
- إعادة محاولة محدودة للأخطاء المؤقتة و429/5xx، ومهلة واضحة بدل تعليق الواجهة.
- الرد يتضمن سياق المصدر الرسمي عند توفره، ولا تعرض الواجهة مفاتيح أو أسرارًا.

## التكامل الخلفي المتحقق

الخدمة الخلفية المستخدمة حاليًا:

```text
https://uijhhj.app.n8n.cloud/
```

مسارا الإنتاج:

```text
POST /webhook/assistant-start
POST /webhook/assistant-status
```

تم اختبار المسار الحي من نطاق GitHub Pages بتاريخ 2026-10-22:

1. `assistant-start` أعاد HTTP 200 و`taskId` صالحًا.
2. `assistant-status` أعاد HTTP 200 وحالة `completed`.
3. الرد الحقيقي للاختبار كان: «عاصمة المملكة العربية السعودية هي الرياض.»
4. رأس CORS سمح بالأصل `https://d2ms79m2st-hub.github.io`.

n8n هنا طبقة تنفيذ خلفية فقط. لا تُحفظ مفاتيح مزود الذكاء الاصطناعي داخل React أو GitHub Pages.

## البيانات والموثوقية

المصدر الرسمي للهوية والتصنيفات والمنتجات هو [baderabalkhail.com](https://baderabalkhail.com). الأسعار والتوفر لقطات تحقق وليست مزامنة لحظية، والمصدر الرسمي هو المرجع النهائي. لا يجوز إضافة منتج أو سعر أو عرض أو مواصفة غير مؤكدة.

## GitHub Pages

Workflow النشر موجود في `.github/workflows/pages.yml`. كل Push إلى `main` يبني نسخة Vite وينشر `dist/public` على GitHub Pages. قبل إعلان نجاح أي إصدار يجب اختبار رابط `/baderai/#/assistant` وإرسال سؤال حي والتحقق من ظهور الرد.

## كتالوج المنتجات الكامل

يحتوي `docs/knowledge/bader-official-catalog.json` و`client/src/data/catalog.ts` على snapshot من 73 منتجًا فريدًا جُمعت من 10 تصنيفات رسمية عبر واجهة Salla العامة مع pagination. صفحة `/store` تعرض الكتالوج كاملًا وتدعم البحث بالاسم أو الوصف أو الفئة، والتصفية حسب التصنيف والسعر وحالة التوفر. لا توجد سلة أو بوابة دفع داخل مساعد بدر؛ كل بطاقة تفتح رابط المنتج الأصلي في المتجر الرسمي.

لتحديث snapshot:

```bash
python3 scripts/sync-bader-catalog.py
```

بعد تشغيل السكربت يجب مراجعة `collectedAt` و`productCount` ثم إعادة توليد `client/src/data/catalog.ts` من JSON قبل النشر. الأسعار والتوفر بيانات مؤرخة، وليست وعدًا لحظيًا؛ المتجر الرسمي هو المرجع النهائي.
